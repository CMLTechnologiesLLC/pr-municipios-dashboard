# 🏛️ Salud Fiscal Municipal · Puerto Rico

Dashboard de la salud fiscal de los 78 municipios de Puerto Rico, basado en el **Índice de Salud Fiscal Municipal** de [ABRE Puerto Rico](https://abrepr.org) / CIPP.

📊 **Ver el dashboard:** [https://cmltechnologiesllc.github.io/pr-municipios-dashboard](https://cmltechnologiesllc.github.io/pr-municipios-dashboard)

## Datos

Período: Años fiscales 2013–2022  
Fuente: [abretumunicipio.org](https://abretumunicipio.org)  
Metodología: Adaptación del Mercatus Center (George Mason University)
